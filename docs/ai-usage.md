# My Personal AI Usage Rules

## Rule 1 - What I will never paste

I will never paste credentials, tokens, API keys, passwords, `.env` contents,
real customer or user data, regulated data, private production configuration,
or code and documents that I am not authorized to share. I will use synthetic
examples or redacted, minimum-necessary snippets instead.

## Rule 2 - What I will always verify before accepting

I will verify AI-generated code against the relevant repository files, tests,
business rules, and public API contracts before accepting it. I will also check
for unsafe assumptions, unintended data exposure, destructive commands, and
changes outside the approved task scope.

## Rule 3 - How I will record AI contributions

For each meaningful AI contribution, I will record the prompt or task, files
changed, checks performed, remaining assumptions, and my final decision to
accept, revise, or reject the result. I remain responsible for every change I
commit.
